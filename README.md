# BeardLib
A large library that assists in mod creation for PAYDAY 2.
- Custom Heists
- Adding files easily
- Multiple modules to make mods without writing any code
- Easy ability to add content. Such as masks, melee weapons, weapon mods, suits, gloves and more
- Script File Manipulation

## Download
You can download a stable release from modworkshop: https://modworkshop.net/mod/14924

`Note:` BeardLib versions 5.1.0 and above only support Diesel 3.0 / 64 bit.

## Dependencies
